# Repository Vocabulary Vertical-Slice Register

## Truth boundary

This generated planning register enumerates every unique intent-like name currently
present in the six detailed workflow catalogs and compact BusinessIntent workflow
registry. It is not the accepted numbered catalog. Each row is a candidate
vertical slice that must be joined to a stable accepted definition, reviewed
extension, alias, event/capability disposition or rejection.

Each row inherits [MAX-v1](maximal-configuration-profile.md), its profile from the
[workflow design registry](../business-intent-workflow-registry.md), its archetype
recipe and the intent-specific/shared delta at the source locator. Expansion uses
the complete [VerticalSliceRecord](README.md#complete-vertical-slice-record).

The kernel hint is deliberately non-authoritative. The accepted IntentDefinition
must select the exact kernel family; generation must report disagreement rather
than silently changing the definition.
