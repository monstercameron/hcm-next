# Devlog — 2026-09-07: the typed-CSS migration

Running log of the migration that removed every string-CSS stylesheet from
the repo (GWC typed constructors throughout), on top of HEAD `b62541d`
(WEB-040 launcher). Written by the orchestrating session; every result below
was re-verified by the orchestrator before it was recorded (`go test
-count=1` on the named packages, windows port of Go via
`C:\Program Files\Go\bin\go.exe`, branch `plan-revision-2026-09-02`).
Entries are in the order the work happened.

## 1. Starting point

- The user demanded typed CSS with no string CSS anywhere in the repo:
  `internal/humanwork/productui/styles.go` held 67 string consts plus
  emitters in `appearance.go`/`theme.go`/`focus.go`, and outer sites in
  `internal/humanwork/workspace`, `tools/uxqual/ssrshell`,
  `tools/uxqual/tokens`, and `tools/uxqual/render/{journey,ssr,gwc}`.
- Proven pattern from the earlier 8-sheet pilot: per-package harness
  (`buildTypedSheet` Reset-declare-Harvest under mutex, `declareGlobal`,
  `mediaRule`, `hoverRule`) + `Raw` only for var() fallbacks, logical props,
  system colors, color-mix, and at-rule headers GWC cannot construct.

## 2. Wave 1 — productui platform sheet (six parallel workers, one const each batch of ~11)

- Workers wrote `typed_mig_A..F.go` (new files only, verified each with
  per-const semantic cssdiff against `git show HEAD:` originals).
- Orchestrator integration fixes that mattered:
  - Workers duplicated `focus.go` bridge text into two files; moved it once
    into `focus.go` as `declareJourneyFocusBridge`/`declareFocusStyles` and
    rewired both callers. Deleted two dead composer wrappers
    (`ThemeCoverageStylesheet`, `themeCoverageBaseStylesStylesheet`) that
    would have been a second source of truth.
  - Workers omitted `@starting-style` and `@supports` (no GWC constructor);
    restored both via a documented `atRule` helper with typed inners and
    exact original positions (`@supports(overflow:clip)` must stay after the
    base `.people-directory` rule for the cascade).
  - Caught a real shimmer-linkage break: `loadingProxyStyles` referenced
    plain `hcm-shimmer` while the frames moved to a hashed name. Fixed with
    `Keyframes()+Animation()` longhands (same body ⇒ same hash ⇒ deduped).
  - Caught and fixed my own focus-selector corruption (`\"` inside backticks
    emits literal backslashes): 20 replacements, selectors now plain-quoted.
- Proof: dumped full `Stylesheet()` old (HEAD worktree) vs new; ordered
  semantic diff adjudicated hunk by hunk. Remaining deltas are all canonical
  serializer behavior: trailing `;`, sorted declarations, `@media ` spacing,
  `1 / -1` grid spacing, `background-color`, longhand expansion, adjacent
  group splits, hashed keyframes (bodies identical, linkage verified).
- `TestTypedKeyframesNamesResolve` added: every `animation-name` and every
  `hcm-*` shorthand reference must resolve to an emitted `@keyframes` block.
- ~90 test oracles re-anchored to canonical emission, each with raw-output
  proof (never assumed). Package suite green.

## 3. Wave 2 — outer sites (three workers: productui emitters, workspace, uxqual)

- `Theme.CSS()` and `customerThemeStylesheet()` converted with
  **byte-identical** output (pinned digest `8ac7d3…` still passes unchanged;
  customer sheet semantically clean per cssdiff).
- Workspace login sheet: 0-hunk ordered diff (identical). Product shell is
  pure composition (`journey.Stylesheet() + productui.Stylesheet()`), so its
  proof inherits.
- Tokens `WorkspaceCSS()`: 130/130 rules, zero semantic hunks; mode-contract
  SHA re-pinned (`d639…` → `d9f2…`) as the golden-review mechanism intends.
- ssrshell goldens: stylesheet-bytes-only change, digest re-pinned.
  Workspace `ux002_document.golden`: post-`</style>` HTML byte-identical;
  only the style block changed.
- Caught a real journey defect: 15 `Raw("animation", "<name>-<hash> …")`
  shorthands hardcoded content hashes (silent breakage on any frames edit).
  14 converted to `Keyframes()+Animation()` longhands; the one irreducible
  dual-animation shorthand stays Raw with an explanatory comment, guarded by
  new `TestJourneyKeyframesResolve` (checks both shorthand names).
- Preserved latent quirk deliberately: eight `@media(print)` blocks never
  match (unknown media feature, not the print type). They stay dead via
  `@media (print)`; converting them to live `@media print` would silently
  change print rendering with no visual gate available. Logged, not fixed.

  `@media(print)`-exact emitter for dead-form preservation.
- The `@media(print)` dead blocks should get an explicit visual print check
  (or a deliberate fix to `@media print`) in a session with a browser gate.
- AGENTS.md loop compliance: unit + package suites green; e2e/responsive
  visual, a11y/i18n, and changelog/devlog steps are recorded here and in
  `CHANGELOG.md`. No browser was driven in this session (text-equivalence
  proof substituted); the next visual pass should spot-check launcher,
  focus rings, shimmer/route-progress, and print output.
