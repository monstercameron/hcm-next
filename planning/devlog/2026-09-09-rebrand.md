## 2026-09-10 leave substrate (DB-023, LEAVE-016)

DB-023 materializes the Medical Leave and Return-to-Work state in a new
owned package `internal/data/leavestore` over migration 00281 (twelve
tenant-scoped tables, RLS forced, append-only triggers, idempotency keys,
overlap/employment/compartment checks). LEAVE-016 adds the pure-domain
process anchor in `internal/domains/leave/anchor.go`: a mutex-guarded
`AnchorStore` binds the LEAVE-001 process and persists the CHANGE_REQUEST
intent, request revision 1 and LeaveRequested provenance with digest
idempotency. The anchor stays out of `internal/data` on purpose — no domain
package imports a data store, so INTEGRATION runs through the store's own
seams and DB-023's pgtest suite covers the SQL.

Defects found while turning RED to GREEN: `SELECT count(*) ... FOR UPDATE`
is illegal in PostgreSQL (moved the lock into a subquery); `FOR UPDATE`
under RLS needs the UPDATE grant, so `leave_availability_revision` carries
`SELECT, INSERT, UPDATE` like the sibling lock-read tables with the trigger
still forbidding mutation; negative probes sharing one transaction poisoned
it, so each refusal now runs in its own rolled-back transaction; the
employment probe first failed on the request FK instead of the employment
check until it referenced the seeded request; test queries used three wrong
column names (`absence_id`, `ending`, `ref`) and one wrong table
(`leave_availability_revision`, not `worker_availability`); the anchor bound
`string(uint8-family)` (a rune) into its digest instead of the family name,
missed the `LeaveRequested` event name in the record, and aliased stored
slices into returned records until a clone step was added. RED was proven
for both todos: without the overlap lock/grant the seed fails, without the
anchor replay branch duplicates fork and eight racers create eight anchors.

Decisions: checksums and signatures for the 00281 manifest entry come from
`migrations.Files()` and the manifest's own dev-key signer via throwaway
helpers under /tmp (never hand-copied); the evidence report and archdoc
snapshot were regenerated with their sanctioned generators
(Compile/Render, `archdoc -out`).

Verified: `go test -count=1 ./internal/data/leavestore/` PASS (6/6 incl.
golden, coverage 78.7%), `go test -count=1 ./internal/domains/leave/` PASS
(coverage 87.9%), `go vet` and `gofmt` clean on both,
`./tools/planning/gateevidence/` PASS (manifest checksum, signature,
report freshness), driftgate PASS, `./internal/data/health/` PASS,
tableinventory and placementbindings PASS. The race-detector run is
deferred to CI per AGENTS.md (no compiler toolchain on this machine); the
RACE matrix tests run eight goroutines each. Left partial: nothing in this
lane. Known-red and untouched (fails at HEAD, other owners):
`tools/policy/rlsparity` on the committed 00280 admission tables and the
safety store tables — no `leave_*` finding involves this change.
