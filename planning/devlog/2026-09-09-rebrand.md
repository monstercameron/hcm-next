GitHub repo rename to `monstercameron/human-capital-management-suite`
(old URL redirects; verified via `gh repo view` on both names):

  comments/UI text/help, TS brand pack (`brand.ts` id/name/logo/alt), JSON
  schema titles, READMEs, CI scripts, live planning specs/design docs.

## Incidents
- `SIGILL` in `tools/gen` traced to a poisoned `GOCACHE` inside the repo
  (`.artifacts/gocache` on the 9P `/mnt/c` mount served bit-flipped build
  archives; disassembly proved identical inputs, different codegen). Moved
  all Go caches to `/tmp`. `.artifacts/` is gitignored; no repo impact.
- `gen/TOOLS.lock` was found downgraded to buf 1.57.2 (policy pins 1.72.0,
  enforced by LIB-019). Restored the lock and regenerated all buf artifacts
  with buf 1.72.0; protoc-gen-go output is byte-identical across the two.
- Phase-one manifest refresh also absorbed pre-existing drift (golden was
  already stale at HEAD: 141/386 vs fresh 155/377 allowlist/deferred). The
  refreshed golden is byte-identical to a HEAD-tree refresh modulo the path
  prefix (verified via worktree diff).

identifiers, dated history (devlogs, CHANGELOG entries, dated audits,

this rename) invalidates its signature — re-signing needs the key holder.
